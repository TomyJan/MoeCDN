# 组件基础样式

## 色彩

整体以灰阶为主，主题色为 `#00dddd`，仅用于品牌、小范围强调和交互焦点。浅色主题采用更暗的青色 `#007c7c` 以保持可读性，不铺大面积主题色背景。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#fafafa` | `#141414` |
| 面板 | `#ffffff` | `#1b1b1b` |
| 悬停 | `#f1f1f1` | `#252525` |
| 选中 | `#eaeaea` | `#303030` |
| 正文 | `#242424` | `#e9e9e9` |
| 次要文字 | `#6b6b6b` | `#a0a0a0` |
| 边框 | `#e5e5e5` | `#303030` |
| 强调 | `#007c7c` | `#00dddd` |

文件名继承当前主题正文色，避免浅色模式出现白字。成功反馈以图标表达，不依赖颜色。

## 字体与图标

主字体 MiSans，界面、列表、数字、预览元数据及网页页脚统一使用。预览正文西文使用 Source Code Pro，中文回退 MiSans。Source Code Pro 暂从 BootCDN 引用，正式版迁移为本站托管。

文件图标使用 VS Code Material Icon Theme 的真实 SVG，操作图标使用 Lucide。保留各自许可。不要用 emoji 替代文件类型图标。

## 组件

- 按钮：灰阶底色与边框，图标按钮通常 36 × 36 px、8 px 圆角。复制成功的图标过渡保留 1 秒。
- 搜索：输入框与范围选择组成单个面板，使用整体 focus-within 边框；范围菜单自绘。
- 下拉菜单：图标、文本、当前选择标记，支持键盘导航，展开和退出均有动画。
- 目录树：缩进层级、独立展开箭头、当前目录背景。箭头旋转和容器高度变化同步。
- 列表：清晰列对齐、轻量分隔与悬停反馈；不使用大块主题色选中背景。
- 预览：大卡片、紧凑单行工具栏、单行元数据底栏；长文件名允许截断，主体保持可用空间。
- 高级复制：紧凑浮层、横排选择卡片、内嵌复制按钮、无多余头部。内容改变时测量真实高度，双向过渡。

## 响应式与动效

桌面为目录侧栏与主列表双栏，移动端将目录收起、次要操作简化。320 px 和 390 px 宽度应无页面横向溢出，弹窗和 popup 保持在视口内。

颜色、阴影、位移、透明度与真实高度变化共同表达状态。菜单约 140–180 ms，目录切换约 380 ms；具体数值以最终 `prototype/style.css` 和 `prototype/app.js` 为准。开启减少动态效果时缩短或跳过动画。
