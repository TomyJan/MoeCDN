# 需求与交互

> 本文仅说明归档原型的交互，不作为当前网站的功能清单。当前网站的搜索、页脚和条款确认等行为见[部署与资源维护](../docs/deployment.md)。

## 目标与地址

替代 h5ai，生成纯静态目录列表。推送文件更新后，由构建流程重新计算索引、生成页面并自动部署到 EO Makers。现有静态文件仍能按原路径访问和引用。

目录 URL 就是页面路由，例如 `/web-static/`，不带 `#`，不额外增加目录列表前缀。支持直达、刷新、前进和后退。访问目录时显示列表；访问 `/某目录/index.html` 时显示该文件原有 HTML。文件请求优先于目录页面规则。

## 页面结构

- 浮动顶栏：品牌、主页、博客、语言和外观图标。下滚隐藏，上滚出现。主页 <https://vov.moe>、博客 <https://blog.tomys.top> 在新标签页打开。
- 语言切换：简体中文和英文，基础架构支持 i18n。触发按钮显示当前语言的“中”或“EN”。
- 外观切换：跟随系统、浅色、深色。按钮仅显示图标，无箭头；菜单内部显示图标和文字。
- 左侧目录树：初始收起，自动展开到当前目录；支持逐项展开、收起和全部收起。移动端收纳到可切换的侧栏。
- 主体：面包屑、目录标题、复制目录链接、搜索、统计、排序、文件表格。面包屑根目录仅使用图标。
- 页脚：`MoeCDN 短提交号`，恰好一个空格、无竖线。分别链接到仓库和完整提交 URL，新标签页打开。原型提交号固定，正式版由构建注入。
- 滚动超过阈值后右下角显示圆形回顶按钮。

文案保持简短，避免重复解释搜索范围、静态资源性质或设计预览状态。统计只显示非零项，例如 `4 个文件 · 259.2 KB`；空列表时隐藏全部统计，由主体提供空状态。

## 列表与搜索

默认在当前目录及其全部子目录递归搜索，可切换为全站。下拉选项只写“当前目录”和“全站”。清空搜索后回到原目录列表。

目录点击进入列表；文件点击打开预览卡片。列表提供名称、大小、修改时间和操作，支持名称升降序、最近修改、体积排序。窄屏合理收纳次要列与操作。

不分页、不提供手动加载更多按钮。靠近底部时自动追加，加载期间在原列表底部左侧显示“加载中…”。原型每批追加 100 项。

## 复制

列表和预览的复制链接按钮直接复制原始地址。按钮本体反馈成功，成功对号保留 1 秒后恢复。目录提供复制目录链接。

高级复制为共享的紧凑 popup，锚定列表或预览中的触发按钮。没有标题、文件名和关闭按钮头部；再次点击同文件触发按钮时关闭。支持点外部和 Escape 关闭。

复制格式与哈希算法分别使用横排卡片。格式包括直链、适用文件的 HTML 标签、Markdown、文件哈希。算法包括 SHA-256、SHA-384、SHA-512，原型默认 SHA-384。

HTML 引用根据类型生成 script、link 或 img；不适用的格式与附加选项直接隐藏。SRI 与 crossorigin 仅对 JavaScript/CSS 的 HTML 引用生效。SRI 行在哈希选项上方；哈希行仅在哈希格式或开启 SRI 时显示。

SRI 与 crossorigin 初始不勾选；在同一 popup 生命周期中切换格式保留勾选状态，关闭后重新打开重置。隐藏选项不影响其他格式输出。缺失哈希时不能输出有效 SRI，正式实现须按此能力约束处理。

复制按钮内嵌在输出文本框内，不重复显示当前算法。可选内容显隐伴随真实高度和透明度变化，动画结束不得跳变。

## 文件预览

文件在居中的弹出卡片内预览，预览主体占据主要区域。顶部同一行排列文件名、模式切换、复制、高级复制、打开原文件、下载和关闭；不重复显示完整路径。

支持文本/代码、图片、音视频、PDF、字体预览；不支持的类型提供打开原文件和下载。HTML 与 Markdown 支持“源码 / 渲染 / 对照”，对照为左右并列；窄屏模式按钮使用图标。

HTML 渲染使用禁用脚本的 sandbox iframe；Markdown 经 marked 解析、DOMPurify 清理后在 sandbox iframe 显示。预览不应执行待浏览文件中的脚本。

底栏左侧显示大小和具体修改时间，不加“修改”前缀、不显示创建时间。右侧依次显示可用的图片尺寸或音视频时长、编码、格式；不重复“HTML 源码”等名称。尺寸与时长来自媒体实际元数据，无法取得时隐藏。

## 动画与可访问性

自绘下拉菜单、目录树、popup 均有进入与退出动画。目录树通过真实内容高度展开/收起，箭头同步旋转。目录层级切换有方向明确的页面动画，原型约 380 ms。

搜索框的聚焦线包围整个组合控件。按钮具备 hover、按下、聚焦和复制成功反馈。支持键盘操作菜单、Escape 关闭、`/` 聚焦搜索，图标按钮提供可访问名称。遵循 `prefers-reduced-motion`。
