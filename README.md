# MoeCDN

[cdn.amoe.cc](https://cdn.amoe.cc) 的新版纯静态目录程序，面向 EO Makers 部署。

`master` 从独立历史开始，目前保存已确认的需求、设计约定及可交互 HTML 原型。正式应用和自动部署流程待实现；旧站及静态资源保留在 [legacy 分支](https://github.com/TomyJan/MoeCDN/tree/legacy)，归档日期为 2026 年 10 月 28 日。

- [设计说明](design/README.md)：需求、视觉规范、交互与技术选型。
- [运行原型](design/prototype/README.md)：`python design/serve.py`，然后访问 <http://127.0.0.1:4178/>。
