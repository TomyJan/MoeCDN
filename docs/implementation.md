# 实施记录

规格和视觉依据保留在 `design/`；实际应用位于 `src/`，构建、索引与本地预览位于 `scripts/`。此前冻结的八个原型源文件保持不变。

## 已作出的实现选择

- 在 `feat/static-directory` 分支实施，保留 `master` 的设计基线；未经用户要求不推送或生产部署。
- 使用 React、TypeScript、Vite、Tailwind 及 Radix 作为组件交互基础。按钮采用 shadcn 常见的 cva/类名组合方式，外观遵循原型而不套默认主题。
- 旧站的公开资源从设计固定提交迁移到 `resources/`，构建时发布到原 URL，不迁移 h5ai 程序。
- 采用两条静态重写覆盖目录 URL，避免为数百个目录生成超出平台数量限制的重写规则。未知斜杠路径显示应用的不存在状态，HTTP 状态为 200；未知文件维持 404。
- 所有字体在正式版随站点发布；原型仍保留原来的 BootCDN 引用作为历史快照。
- PDF 采用独立加载的 PDF.js，页面靠近视口时绘制 canvas，HTML / Markdown 继续使用禁止脚本的沙箱。

## 验证进度

- 索引、递归搜索、路径编码和复制输出：先执行失败用例，再实现，通过 6 个单元测试。
- React 页面未实现时，6 组浏览器行为测试全部失败；接入实现后逐项通过。
- 首轮浏览器测试发现语言图标文字参与菜单可访问名称，修复装饰图标的 ARIA 标记后通过。
- 生产依赖审计发现 DOMPurify 旧版漏洞，更新到修复版本后无已知漏洞。
- 独立代码审查发现三个重要问题：Chromium 阻止沙箱内原生 PDF 插件、`.mjs` 复制缺少模块类型，以及不同时区时间字符串排序错误。均已添加先失败的回归用例并修复；最终结果见下方交付验证。
